PVZ CONTROL v1.3 TEST
Добавлены графики рассрочек по происшествиям (без автоматических удержаний), перенос/замена плановых смен, копирование по правилу, экспорт календаря в настоящий XLSX и печать в PDF через системный диалог.
Данные хранятся только локально. Перед обновлением сделайте резервную копию JSON. Серверной авторизации и синхронизации нет.

Исправление сохранения ПВЗ: при открытии старых баз недостающие поля добавляются в оперативную модель. Сравнение с localStorage теперь происходит по снимку, снятому ДО изменения, а не по сериализации обновлённой модели. Реальные изменения в другой вкладке по-прежнему блокируются. Ошибки формы показываются внутри формы. Ключ хранения данных не изменён.
