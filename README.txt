PVZ CONTROL v0.4 — локальная тестовая сборка
Откройте index.html в браузере. Данные хранятся в localStorage только на этом устройстве.
Изменения: отделение фактических начислений от планового прогноза, часы и почасовая ставка, проверка пакетных конфликтов, исключение для управляющих, проверка сумм, предотвращение дублирующихся назначений, улучшения мобильного отображения.
Автоматические проверки Node.js: 9 сценариев пройдены. Тестирование на iPhone/Telegram не выполнено.
ОГРАНИЧЕНИЯ: нет серверной авторизации и синхронизации; нет защищённых серверных резервных копий; системные prompt/confirm не заменены мобильными формами; нет полной финансовой модели, прав пользователей и детальной статистики; локальное хранение не подходит для эксплуатации с реальными финансовыми данными.
